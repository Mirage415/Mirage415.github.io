# Yushen Liang — personal research website

Public website: https://mirage415.github.io/

Buildless HTML, CSS, and JavaScript. GitHub Pages serves the root of `main`.

## Local preview

Run `python3 -m http.server 8765` and visit http://localhost:8765.

## Content

- `index.html`: biography, teaching, news, hobbies, and static publication markup.
- `script.js`: publication data, filters, citation dialog, and conceptual trajectory animation. Keep static publication markup in sync when changing paper data.
- `style.css`: responsive layout and reduced-motion support.
- `assets/tfp-overview.jpg`: figure from the author's public TFP repository.
